# My Third Post

This is an example of how easy it is to add a new post to your blog.

## Just Write Markdown

No configuration needed. Just:

1. Create a markdown file in the `posts/` directory
2. Add frontmatter (optional)
3. Write your content
4. Commit and push

GitHub Actions will automatically build and deploy your site!

## Clean URLs

Each post gets its own URL path based on the filename. For example, this file `2026-01-06-my-third-post.md` would be accessible at:

```
https://yourusername.github.io/blog/my-third-post/
```

That's it! Happy blogging!
