# Welcome to My Blog

Hello and welcome! This is my minimal, text-only blog built with a static site generator. Posts are written in Markdown, making it easy to write and maintain content.

## Why a minimal blog?

In an age of complexity, sometimes simplicity is refreshing. This blog focuses on what matters most: the content. No heavy frameworks, no databases, just pure static files that load instantly.

## Features

- **Markdown support**: Write posts in plain Markdown
- **Lightning fast**: Pure static HTML generated at build time
- **GitHub Pages ready**: Automated deployment with GitHub Actions
- **Clean and readable**: Focused on typography and readability
- **Direct URLs**: Each post has its own clean URL path

## Getting Started

To add a new post:

1. Create a new `.md` file in the `posts` directory
2. Add frontmatter with title and date
3. Commit and push to GitHub

That's it! GitHub Actions will automatically build and deploy your post.

Enjoy writing!
